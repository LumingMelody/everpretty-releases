# everpretty releases

这是 everpretty 桌面应用的**发布仓库**，只存放安装包和应用内自动更新使用的更新清单（`latest.json`），不包含源码。

- 下载：见 [Releases](https://github.com/LumingMelody/everpretty-releases/releases)
- macOS（Apple 芯片）：`everpretty-<版本>-mac-arm64.dmg`
- Windows 10/11 x64：`everpretty-<版本>-win-x64-setup.exe`
- 安装包均未签名：macOS 首次打开需右键 → 打开；Windows 会出现 SmartScreen 提示。
- 0.5.1 起支持应用内检查更新。
